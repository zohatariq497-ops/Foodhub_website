# Foodhub_website

A food ordering website built with AI (Lovable) featuring burgers, pizzas, noodles and sweets menus.

## Live Website
https://order-joy-deluxe.lovable.app/

## Features
- Menu pages for Burgers, Pizzas, Noodles and Sweets
- Add to cart and order option
- Contact page
- Mobile friendly design

## Tool Used
Lovable (AI website builder)
